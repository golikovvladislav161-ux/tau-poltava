# TAU POLTAVA
`index.html` — головна сторінка. Чотири сценарні кнопки ведуть на `menu.html` з параметром mode. `menu.html` — попередній прототип меню; його UX буде доопрацьований окремо за вказівками користувача.

Фонове фото збережене у `assets/hero.jpg`. Google Maps вбудована для TAU, вул. Соборності, 44, Полтава. Контакти та години взяті з відкритих довідників; години роботи треба підтвердити з рестораном перед публікацією.

Поки що це статичний фронтенд-прототип, не production-система: замовлення, оплата, бронювання та корпоративні заявки ще не підключені до сервера.
